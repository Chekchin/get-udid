ទាញយក UDID របស់ iPhone / iPad របស់អ្នកបានយ៉ាងងាយ ក្នុងរយៈពេលតែប៉ុន្មានវិនាទី

⚠️ សូមបើកគេហទំព័រនេះក្នុង Safari នៅលើ iPhone / iPad របស់អ្នក។
ទាញយក UDID
  1. ចុចប៊ូតុងខាងលើ ហើយអនុញ្ញាត Allow
  2. បើក Settings → ចុច Profile Downloaded (ឬ General → VPN & Device Management)
  3. ចុច Install ហើយបញ្ចូលលេខសម្ងាត់ទូរស័ព្ទ
  4. ប្រព័ន្ធនឹងបើកទំព័រ UDID របស់អ្នកដោយស្វ័យប្រវត្តិ

🔒 Profile នេះអានតែ UDID ប៉ុណ្ណោះ ហើយអ្នកអាចលុបវាចេញពី Settings បានគ្រប់ពេល។
